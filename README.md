# بعد مأرب

لعبة استراتيجية/استكشاف مبنية على React + Vite + TanStack Start، ومصممة كنسخة لعب قابلّة للتجربة على الويب. المشروع يقدّم عالمًا صغيرًا قائمًا على الموارد، البنية، الجيش، التطوير، المعسكر، وتفاعلات العالم.

## ما الذي يتضمنه المشروع

- خريطة تفاعلية للمدينة والوادي
- نظام موارد: الماء، الغذاء، الذهب، الخشب، الحجر، السكان
- نظام بناء وتطوير مبانٍ ومراعي وزراعة
- نظام تدريب جيش وعمليات هجومية واستطلاع
- نظام تقارير، ديوان، رسائل، ومقترح مرشد في اللعبة
- قاعدة بيانات داخلية مدمجة، مع دعم مصادقة عند الحاجة

## التقنيات

- React 19
- Vite 8
- TanStack Start / Router / Query
- Tailwind CSS
- PGlite + Postgres-ready
- Better Auth (اختياري حسب حالة المصادقة)

## المتطلبات

- Node.js 22+
- npm

## التشغيل محليًا

```bash
npm install
npm run dev
```

تفتح اللعبة على:

- http://localhost:8080

## أوامر المشروع

```bash
npm run dev
npm run build
npm run typecheck
npm run test
npm run lint
```

## متغيرات البيئة

أنشئ ملف `.env` من النسخة النموذجية:

```bash
cp .env.example .env
```

النسخة النموذجية تحتوي على المتغيرات الأساسية، مع قيم افتراضية أو placeholders. لا تضع الأسرار الحقيقية في الـ repo.

## إعداد النشر

المشروع جاهز للبناء على Vercel مع إعداد بيئة الإنتاج الصحيح، وبشكل خاص:

- DATABASE_URL
- BETTER_AUTH_SECRET
- BETTER_AUTH_URL
- GROK_AUTH_ISSUER
- GROK_AUTH_CLIENT_ID
- GROK_AUTH_CLIENT_SECRET
- VITE_AUTH_ENABLED

## ملاحظات مهمة

- لا تضع secrets في الملفات أو الاستوديو المحلي.
- لا تنشر قبل التحقق من أن بيئة الإنتاج تستخدم المتغيرات الصحيحة.
- في وضع المصادقة، تأكد من أن جميع server functions تستخدم `authMiddleware`.
- إذا كانت اللعبة ستُستخدم كنسخة تجريبية/ألفا، فالأمر مقبول. أما إذا كانت تريد إطلاق تجاري، فإضافة QA + balance + analytics + monetization مطلوب.
